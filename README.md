# STM32F407 多参数水质监测系统

基于 STM32F407ZGT6 的水质监测系统底层实现，当前完成设备通信、任务调度、配置保存和采集记录存储，真实水质传感器尚未接入。

## 功能概览

- 通过 RS485 建立设备通信链路
- 基于 Modbus RTU 实现监测主机寄存器读写
- 使用 FreeRTOS 管理通信、采集、配置和存储任务
- 使用 AT24C02 EEPROM 保存设备配置
- 使用 SPI 和 FatFs 将采集记录保存到 SD 卡
- 支持单次采集、周期采集和预约采集
- 提供 Python 命令行工具，用于设备查询、配置和控制
- 处理通信超时、非法请求和部分链路异常

当前采集数据为程序生成的测试数据，不代表真实水质测量结果。

## 硬件连接

系统由两块 STM32F407ZGT6 开发板组成：

```text
Mac（Modbus 主站）
        │ USB 串口
        ▼
板 B（透明桥接）
        │ RS485
        ▼
板 A（监测主机 / Modbus 从站）
```

- **Mac**：发送 Modbus 查询、配置和控制命令
- **板 B**：负责串口与 RS485 之间的数据转发，不解析 Modbus 业务
- **板 A**：处理 Modbus 请求，管理采集任务，并保存配置和采集记录

板 B 用于临时替代 USB 转 RS485 转换器。更换为标准 USB 转 RS485 适配器后，板 A 固件和上位机命令不需要修改。

## 通信协议

板 A 作为 Modbus RTU 从站，支持以下功能码：

- `03`：读取保持寄存器
- `04`：读取输入寄存器
- `06`：写入单个保持寄存器
- `10`：写入多个保持寄存器

通信过程中检查设备地址、报文长度和 CRC16，并对非法功能码、地址或数据返回异常响应。

RS485 用于底层电气通信，Modbus RTU 用于定义报文格式和设备命令。USART 采用中断方式收发，发送完成后切换 RS485 收发方向。

## 任务与数据存储

FreeRTOS 下按功能划分通信、采集、配置和存储任务：

- **通信任务**：接收并处理 Modbus 请求
- **采集任务**：生成或读取采集数据
- **配置任务**：应用和保存设备配置
- **存储任务**：将采集记录写入 SD 卡

两种存储介质的用途不同：

- **AT24C02 EEPROM**：保存设备地址、采集配置等少量参数，支持掉电保存
- **SD 卡**：保存持续产生的采集记录，通过 SPI 和 FatFs 访问

## 目录结构

```text
firmware/
├── board_a/       # 板 A：监测主机、Modbus 从站和任务调度
├── board_b/       # 板 B：透明 RS485 桥接
├── app/           # EEPROM、SD 卡、调试串口等应用代码
├── bsp/           # STM32F4 标准库、FreeRTOS 和板级支持代码
└── build/         # 构建脚本和链接文件

tests/             # 主机测试和部分仿真测试
tools/             # Python Modbus 命令行工具和串口工具
```

## 编译

需要 ARM GNU Toolchain，并确保 `arm-none-eabi-gcc` 已加入环境变量，或安装在构建脚本默认查找的位置。

在项目根目录执行：

```bash
# 编译板 A 监测主机
./firmware/build/build_board_a.sh

# 编译板 B 透明桥接
./firmware/build/build_board_b.sh
```

生成文件位于：

```text
build/board_a/
build/board_b/
```

每个目录下包含对应的 `.elf`、`.bin` 和 `.hex` 文件。

## 上位机工具

`tools/modbus_cli.py` 提供以下操作：

- 查询设备身份和状态
- 读取、写入寄存器
- 修改并保存配置
- 启动或停止单次、周期采集
- 查看记录状态和原始通信帧

查看命令参数：

```bash
python3 tools/modbus_cli.py --help
```
